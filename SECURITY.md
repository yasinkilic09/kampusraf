# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities publicly before they are reviewed.

Use the public security policy page for the current reporting route:

https://www.kampusraf.com/security-policy

When reporting, include:

- A short description of the issue.
- Steps to reproduce.
- Affected URL or feature.
- Potential impact.
- Screenshots or logs if available.

## Scope

In scope:

- KampusRaf web application.
- Public API endpoints owned by KampusRaf.
- Authentication, authorization, privacy, and user data handling issues.

Out of scope:

- Social engineering.
- Physical attacks.
- Automated high-volume testing without prior permission.
- Third-party services outside KampusRaf control.

## Safe testing

Do not access, modify, delete, or exfiltrate data that does not belong to you.
Avoid tests that degrade availability or generate excessive traffic.
